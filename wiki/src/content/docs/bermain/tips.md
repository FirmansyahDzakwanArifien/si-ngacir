## Tips

1. **Median hijau adalah zona aman.** Berhenti di sana untuk membaca pola lalu lintas berikutnya.
2. **Truk lambat tapi panjang** dan merusak paket 2 kotak. Jangan memotong tepat di depannya.
3. **Perhatikan arah lane.** Lane yang bersebelahan melaju berlawanan arah.
4. **Klakson adalah peringatan.** Bila terdengar "Tin tin!", segera menyingkir.
5. **Hari 2 (galon):** langkah lebih lambat, jadi mulai menyeberang lebih awal.
6. **Hari 3 (telur):** satu tabrakan motor sudah merusak 2 kotak. Lebih baik telat sedikit daripada telur pecah.
7. **Saat hujan:** melangkah di aspal basah bisa tergelincir. Jangan berhenti tepat di depan lane berbahaya.
8. **Kucing menghalangi?** Geser satu petak ke kiri atau kanan, lalu lanjut maju.
9. **Ambil helm sebelum sungai.** Helm juga menahan satu kali tercebur.
10. **Bonus ETA vs. keamanan:** denda kerusakan biasanya lebih mahal daripada bonus tepat waktu.

## Masalah umum

| Masalah | Solusi |
| --- | --- |
| Web tidak ada suara | Klik atau tap layar sekali, lalu cek volume di Pengaturan |
| Web hanya layar hitam atau loading terus | Pakai Chrome, Edge, atau Firefox terbaru dengan WebGL 2 aktif. Coba muat ulang paksa (Ctrl+F5) |
| Versi baru belum muncul di browser | Muat ulang paksa (Ctrl+F5) atau buka di jendela penyamaran |
| Windows memblokir `SiNgacir.exe` | SmartScreen: **More info → Run anyway** |
| APK baru tidak bisa dipasang di atas versi lama | Hapus versi lama dulu, lalu pasang versi baru |
| Game terasa lambat di HP | Matikan **Efek cahaya** dan **Tampilan 3D** di Pengaturan |
| Ingin mengulang dari awal | Menu utama → **Mulai Baru** (tekan dua kali) |
| Tampilan terlalu kecil atau besar | Game menyesuaikan diri dengan bentuk layar. Di HP, putar ke posisi tegak untuk melihat lebih banyak jalan |

Menemukan bug? Laporkan lewat kolom komentar di [halaman itch.io](https://cyphera-game.itch.io/si-ngacir), sertakan perangkat, browser, dan versi game.

## Di mana bisa main?

| Platform | Cara |
| --- | --- |
| **Browser** (laptop atau HP) | Buka [halaman itch.io](https://cyphera-game.itch.io/si-ngacir), tekan **Run game**, lalu klik atau tap layar sekali supaya suara aktif |
| **Windows** | Unduh `SiNgacir-windows.zip`, ekstrak, lalu jalankan `SiNgacir.exe`. Tidak perlu instalasi |
| **Android** | Unduh dan pasang `SiNgacir-android.apk` |

:::tip[HP]
Di HP, posisi tegak (potret) paling nyaman: petak lebih besar dan jalan di depan lebih banyak terlihat.
:::

:::caution[Windows SmartScreen]
Game belum memiliki tanda tangan digital. Bila Windows memblokir `SiNgacir.exe`, pilih **More info → Run anyway**.
:::

**Kebutuhan minimal**

- Browser: Chrome, Edge, atau Firefox terbaru dengan WebGL 2.
- Windows: Windows 10 64-bit, kartu grafis yang mendukung OpenGL 3.3.
- Android: HP yang mendukung OpenGL ES 3.0.

## Kontrol

| Aksi | Keyboard | Layar sentuh |
| --- | --- | --- |
| Maju | W / ↑ | Tap layar atau swipe ke atas |
| Mundur | S / ↓ | Swipe ke bawah |
| Kiri / kanan | A / ← , D / → | Swipe ke kiri / kanan |
| Pause | Esc / P | Tombol **II** di pojok kanan atas |
| Pilih tombol menu | Enter / klik | Tap |
| Lanjut cutscene | Enter / klik | Tap |
| Lewati cutscene | Esc | Tombol **Lewati** |
| Mode Auto cutscene | Tombol **Auto** | Tombol **Auto** |

Tahan tombol arah untuk melangkah terus-menerus.

## Menu utama

| Menu | Fungsi |
| --- | --- |
| **Lanjutkan** | Melanjutkan dari hari terakhir yang belum selesai, diawali ringkasan singkat **Sebelumnya…** |
| **Mulai Baru** | Memulai dari awal. Tekan dua kali, karena progres lama terhapus |
| **Toko Masbro** | Belanja aksesori dengan koin. Lihat [Toko Masbro](/fitur/toko/) |
| **Album Cerita** | Menonton ulang cutscene. Lihat [Cutscene & Album](/fitur/album/) |
| **Pengaturan** | Volume, bahasa, layar penuh, tips tutorial, aksesibilitas. Lihat [Pengaturan](/fitur/pengaturan/) |
| **Keluar** | Menutup game (desktop) |

Progres tersimpan **otomatis** setiap kali satu hari selesai. Keluar di tengah hari berarti mengulang hari itu dari awal.

**Tips tutorial** muncul sekali saat kamu pertama kali bertemu sesuatu yang baru: koin, power-up, lubang, sungai, Pos, kios jemput, dan lainnya.

Selanjutnya: [Aturan & Upah](/bermain/aturan/).

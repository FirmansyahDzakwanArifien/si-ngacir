Open **Settings** from the main menu or the pause menu.

## General

| Option | What it does |
| --- | --- |
| **Music / sound effects / NPC voices volume** | Sets the loudness of each. While an NPC speaks, the music dips briefly so the voice stays clear |
| **Mute all sound** | Silences everything at once. On a keyboard, just press **M** |
| **Fullscreen** | Desktop only |
| **Language** | Indonesian or English (from the main menu). Defaults to your device language |
| **Tutorial tips** | Turn off, or turn back on to replay all tips |
| **Vibrate on collision** | Phone only |

The game **pauses automatically** when you leave the browser tab, the window loses focus, or the phone app is minimized.

## Accessibility

| Option | What it does |
| --- | --- |
| **Text size** | Normal, Large, or Extra Large. Applies immediately on every screen |
| **Color blindness** | Color-correction filter for Protanopia (red), Deuteranopia (green), or Tritanopia (blue) |
| **Reduce motion** | Turns off screen shake, the flash and spin on collision, confetti, pop animations, timer pulsing, moving cloud shadows, and sun rays. Screen transitions become simple fades |
| **Lighting effects** | Warm color filter, sun rays, and darkened screen corners. Turn off if your phone feels slow or the image looks unclear |

## 3D View (beta)

Under **Settings → More → 3D view (beta, heavier)**, the road is drawn in 3D with an angled camera. The rules, HUD, and controls are exactly the same as the 2D version. The setting takes effect when the next day starts.

| Platform | Status |
| --- | --- |
| Windows | Available (beta) |
| Android | Available (beta), not yet tested on many phones |
| Browser | Available (beta). Some browsers still have display issues that are being fixed |

:::caution
3D View is heavier than 2D. If the game stutters, turn this option off. On phones, real-time shadows are disabled to keep it lighter.
:::

Technical details are in [Development → 3D View](/en/pengembangan/tampilan-3d/).

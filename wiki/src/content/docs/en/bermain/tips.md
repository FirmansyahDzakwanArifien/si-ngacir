## Tips

1. **Green medians are safe zones.** Stop there to read the next traffic pattern.
2. **Trucks are slow but long** and deal 2 boxes of package damage. Don't cut right in front of them.
3. **Watch the lane direction.** Adjacent lanes travel in opposite directions.
4. **A horn is a warning.** If you hear "Tin tin!", get out of the way.
5. **Day 2 (water jug):** your steps are slower, so start crossing earlier.
6. **Day 3 (eggs):** a single motorbike hit already costs 2 boxes. Better a little late than broken eggs.
7. **In the rain:** stepping on wet asphalt can make you slip. Don't stop right in front of a dangerous lane.
8. **A cat in the way?** Step one tile left or right, then keep going.
9. **Grab a helmet before the river.** The helmet also absorbs one fall into the water.
10. **ETA bonus vs. safety:** damage fines usually cost more than the on-time bonus.

## Common problems

| Problem | Fix |
| --- | --- |
| No sound on the web version | Click or tap the screen once, then check the volume in Settings |
| Web version shows only a black screen or keeps loading | Use the latest Chrome, Edge, or Firefox with WebGL 2 enabled. Try a hard reload (Ctrl+F5) |
| The new version doesn't show up in the browser | Hard reload (Ctrl+F5) or open it in a private window |
| Windows blocks `SiNgacir.exe` | SmartScreen: **More info → Run anyway** |
| A new APK won't install over the old version | Uninstall the old version first, then install the new one |
| The game feels slow on a phone | Turn off **Lighting effects** and **3D View** in Settings |
| Want to start over | Main menu → **New Game** (press twice) |
| The display is too small or too large | The game adapts to your screen shape. On a phone, rotate to portrait to see more of the road |

Found a bug? Report it in the comments on the [itch.io page](https://cyphera-game.itch.io/si-ngacir), including your device, browser, and game version.

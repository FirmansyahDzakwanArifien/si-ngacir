## Where can I play?

| Platform | How |
| --- | --- |
| **Browser** (laptop or phone) | Open the [itch.io page](https://cyphera-game.itch.io/si-ngacir), press **Run game**, then click or tap the screen once to enable sound |
| **Windows** | Download `SiNgacir-windows.zip`, extract it, and run `SiNgacir.exe`. No installation needed |
| **Android** | Download and install `SiNgacir-android.apk` |

:::tip[Phone]
On a phone, portrait orientation is the most comfortable: tiles are bigger and you can see more of the road ahead.
:::

:::caution[Windows SmartScreen]
The game is not digitally signed yet. If Windows blocks `SiNgacir.exe`, choose **More info → Run anyway**.
:::

**Minimum requirements**

- Browser: latest Chrome, Edge, or Firefox with WebGL 2.
- Windows: Windows 10 64-bit, a graphics card that supports OpenGL 3.3.
- Android: a phone that supports OpenGL ES 3.0.

## Controls

| Action | Keyboard | Touchscreen |
| --- | --- | --- |
| Forward | W / ↑ | Tap the screen or swipe up |
| Back | S / ↓ | Swipe down |
| Left / right | A / ← , D / → | Swipe left / right |
| Pause | Esc / P | **II** button in the top-right corner |
| Select menu button | Enter / click | Tap |
| Advance cutscene | Enter / click | Tap |
| Skip cutscene | Esc | **Skip** button |
| Cutscene Auto mode | **Auto** button | **Auto** button |

Hold a direction key to keep stepping.

## Main menu

| Menu | What it does |
| --- | --- |
| **Continue** | Resumes from the last unfinished day, starting with a short **Previously…** recap |
| **New Game** | Starts from the beginning. Press it twice, since your old progress is erased |
| **Masbro's Shop** | Buy accessories with coins. See [Masbro's Shop](/en/fitur/toko/) |
| **Story Album** | Rewatch cutscenes. See [Cutscenes & Album](/en/fitur/album/) |
| **Settings** | Volume, language, fullscreen, tutorial tips, accessibility. See [Settings](/en/fitur/pengaturan/) |
| **Quit** | Closes the game (desktop) |

Progress is saved **automatically** each time you finish a day. Quitting mid-day means replaying that day from the start.

**Tutorial tips** appear once, the first time you encounter something new: coins, power-ups, potholes, rivers, checkpoints, the pickup stall, and more.

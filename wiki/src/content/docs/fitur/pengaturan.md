Buka **Pengaturan** dari menu utama atau dari menu pause.

## Umum

| Opsi | Fungsi |
| --- | --- |
| **Volume musik / efek suara / suara NPC** | Atur keras suara masing-masing. Saat NPC bicara, musik turun sebentar supaya suaranya jelas |
| **Bisukan semua suara** | Membisukan semuanya sekaligus. Di keyboard cukup tekan **M** |
| **Layar penuh** | Khusus desktop |
| **Bahasa** | Bahasa Indonesia atau English (dari menu utama). Bawaannya mengikuti bahasa perangkat |
| **Tips tutorial** | Matikan, atau nyalakan lagi untuk mengulang semua tips |
| **Getar saat menabrak** | Khusus HP |

Game **otomatis pause** saat tab browser ditinggal, jendela kehilangan fokus, atau aplikasi HP diminimalkan.

## Aksesibilitas

| Opsi | Fungsi |
| --- | --- |
| **Ukuran teks** | Normal, Besar, atau Sangat Besar. Berlaku langsung di semua layar |
| **Buta warna** | Filter koreksi warna untuk Protanopia (merah), Deuteranopia (hijau), atau Tritanopia (biru) |
| **Kurangi efek gerak** | Mematikan goyangan layar, kilat dan putaran saat tertabrak, konfeti, animasi pop, denyut timer, gerak bayangan awan, dan sinar matahari. Transisi layar menjadi pudar biasa |
| **Efek cahaya** | Filter warna hangat, sinar matahari, dan sudut layar gelap. Matikan bila HP terasa lambat atau gambar kurang jelas |

## Tampilan 3D (beta)

Di **Pengaturan → Lainnya → Tampilan 3D (beta, lebih berat)**, jalanan digambar dalam 3D dengan kamera menyerong. Aturan main, HUD, dan kontrol sama persis dengan versi 2D. Pengaturan berlaku saat hari berikutnya dimulai.

| Platform | Status |
| --- | --- |
| Windows | Tersedia (beta) |
| Android | Tersedia (beta), belum diuji di banyak HP |
| Browser | Tersedia (beta). Di sebagian browser masih ada kendala tampilan yang sedang diperbaiki |

:::caution
Tampilan 3D lebih berat daripada 2D. Bila game terasa patah-patah, matikan opsi ini. Di HP, bayangan real-time dimatikan supaya lebih ringan.
:::

Detail teknisnya ada di [Pengembangan → Tampilan 3D](/pengembangan/tampilan-3d/).
